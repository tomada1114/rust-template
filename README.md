# tauri-template

A template for personal macOS desktop apps: a Rust core, a Tauri v2 shell, and a
React + Vite + TypeScript screen, distributed as a `.dmg`.

**Status: design agreed, implementation in progress.** The design lives in
[docs/template/design.md](docs/template/design.md), and the triage of the sibling
template's open issues in [docs/template/issue-triage.md](docs/template/issue-triage.md).
